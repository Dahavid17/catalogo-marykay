# Catálogo Mary Kay

Projeto desenvolvido para uma cliente com o objetivo de apresentar produtos de forma organizada, moderna e acessível através de um catálogo digital.

---

## Tecnologias Utilizadas
- HTML5
- CSS3
- JavaScript
- Git
- GitHub

---

## Sobre o Projeto
O projeto foi criado para atender uma necessidade real de divulgação de produtos, oferecendo uma interface simples, intuitiva e visualmente agradável para facilitar a navegação e apresentação dos itens.

Além de servir como catálogo digital, o projeto também teve como foco a aplicação prática de conhecimentos em desenvolvimento web e organização de interfaces.

---

## Funcionalidades
- Exibição de produtos em formato de catálogo
- Organização visual intuitiva
- Navegação simples e acessível
- Estrutura preparada para futuras melhorias
- Layout pensado para melhor experiência do usuário

---

## Aprendizados
Durante o desenvolvimento deste projeto, foram aprimorados conhecimentos em:
- Estruturação de páginas com HTML
- Estilização e responsividade com CSS
- Interatividade com JavaScript
- Organização de projetos
- Uso de Git e GitHub para versionamento
